# Design System: Amanah Study Abroad

## Core Identity
Amanah Study Abroad is a premier educational and student visa consultancy service based in Lahore, Pakistan. The brand identity is built around trust (*Amanah*), ambition, and global reach. The design evokes academic authority, integrity, and prestige — inspired directly by the logo's deep navy blue and vibrant crimson red color scheme.

**Brand Tagline:** Your Dreams • Our Guidance

## Color Palette
Derived directly from the official `amanah_logo.png`:

| Token              | Hex       | Usage                                                          |
|--------------------|-----------|----------------------------------------------------------------|
| `--primary`        | `#031F3F` | Deep Midnight Navy Blue — headings, main brand typography, cards |
| `--primary-light`  | `#0A315E` | Royal Navy — hover states, interactive elements                |
| `--primary-dark`   | `#011227` | Midnight Navy Dark — depth, dark overlays                      |
| `--secondary`      | `#EEF3F8` | Crisp Ice/Slate Blue — section backgrounds, soft contrast cards |
| `--secondary-light`| `#F8FAFC` | Light Crisp White/Slate — clean surfaces                       |
| `--accent`         | `#B70D3D` | Vibrant Crimson / Ruby Red — CTA buttons, badges, highlights   |
| `--accent-light`   | `#D41246` | Bright Crimson Red — CTA hover states, energetic accents       |
| `--accent-dark`    | `#8A072C` | Deep Crimson — shadows, active states                          |
| `--background`     | `#FFFFFF` | Clean White                                                    |
| `--foreground`     | `#031F3F` | Deep Midnight Navy — primary text                              |
| `--bg-soft`        | `#F0F4F9` | Ice Mist — alternating section backgrounds                     |

### Color Usage Rules
- **Primary** (`#031F3F`): Brand title in navbar, primary headings, dark CTA blocks, text.
- **Accent** (`#B70D3D`): "STUDY ABROAD" sub-header, CTA action buttons, highlight badges, checkmarks, airplane swoosh accent.
- **Secondary** (`#EEF3F8`): Hero background tint, footer background, soft feature cards.
- **White** (`#FFFFFF`): Main cards, form containers, elevated elements.

---

## Typography
- **Primary Font**: `'Inter'`, sans-serif (loaded via `next/font/google`)
- **Headings**: Bold/Black weight, tight tracking (`tracking-tighter` or `tracking-tight`)
- **Body**: Regular (400) & Medium (500), line height 1.6–1.75
- **Labels / Badges**: `font-black`, `tracking-widest`, `uppercase`, `text-xs` or `text-[10px]`
